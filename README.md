# OmniLauncher

One Android launcher, four switchable shells: Classic, Metro, Motion 3D, Gaming.
Starter scaffold from the OmniLauncher blueprint (Phase 1-3 skeleton).

## Status
- Registers as a HOME launcher
- Shell interface + ShellManager (selection saved in DataStore)
- Classic: searchable, resizable app grid
- Metro: live-tile flip start screen + A-Z list (swipe left)
- Gaming: library of apps flagged as games
- Motion 3D: rotating clock stub

## Build
Open in Android Studio (Koala+), or push to GitHub and download the APK from the Actions run.
